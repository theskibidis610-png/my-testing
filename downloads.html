Installation

1. Install Fabric

Download Fabric Loader from fabricmc.net and install it for Minecraft 1.21.1

2. Install Fabric API

Download Fabric API and put it in your .minecraft/mods folder

3. Drop Y0 JAR

Put the Y0 .jar file into your .minecraft/mods folder alongside Fabric API

4. Launch

Launch Minecraft with the Fabric profile. Press Right Shift to open the ClickGUI
