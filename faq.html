Common questions about Y0 answered below. Can't find what you're looking for? Join the Discord.

Y0 offers two plans: a Monthly plan at €5/month that you can cancel anytime, and a Lifetime plan at €10 as a one-time payment. Both plans include full access to all 500+ modules, the ClickGUI, config system, and all future updates.
Y0 is built for Minecraft Java Edition 1.21.11 using the Fabric mod loader. It's specifically optimized for EDC server gameplay and 1.21.11 combat mechanics.
1. Install Fabric Loader for Minecraft 1.21.11 from fabricmc.net.
2. Download Fabric API and put it in your .minecraft/mods folder.
3. After purchasing, you'll receive the Y0 .jar file. Put it in your .minecraft/mods folder.
4. Launch Minecraft with the Fabric 1.21.11 profile.
5. Press Right Shift in-game to open the ClickGUI.

You need Java 21 or newer installed on your system.
EDC is a Minecraft PvP server. Y0 is specifically built and optimized for EDC server gameplay, with modules tuned for EDC's meta including crystal PvP, surround, bed bombing, and anchor mechanics.
Y0 has 500+ modules across 6 categories: Combat (85), Movement (87), Render (87), Player (85), World (79), and Misc (79). Every module has configurable settings including toggles, number sliders, and mode selectors.
Press Right Shift to open the ClickGUI. You'll see draggable panels for each module category. Click a module name to toggle it, and click the settings icon to adjust its options. Press Escape to close it.

Y0 saves all module settings to JSON files in your .minecraft/y0/ folder. Settings are automatically saved when you change them and loaded when you launch the game. You can share config files with other Y0 users.
