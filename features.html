🛠 Feature Overview

Built to Win

Every module is purpose-built for competitive play. Here's what Y0 puts in your hands.

Combat Suite

A full arsenal of combat modules tuned for 1.8 and modern PvP. Configurable aim assist, reach adjustments, auto-clicker with humanized patterns, and crystal aura for 1.19+ servers.

  • KillAura with smart targeting
  • Velocity customization
  • AutoCrystal + BedAura
  • W-Tap and combo assistant
⚔️

Movement Engine

Move faster and smarter with speed, fly, and strafe modules. Includes server-specific configs for Hypixel, Lunar, and more.

  • Speed with bypass modes
  • LongJump + HighJump
  • Flight with damage mode
  • Scaffold with tower
💨

Visual & ESP

See everything. Player ESP, tracers, nametags, chest finder, and fullbright. Customize colors, outlines, and rendering modes.

  • Player & entity ESP
  • Storage ESP + item finder
  • Custom crosshair + indicators
  • Shader-based chams
👁

HUD Editor

Drag-and-drop interface to build your perfect overlay. Arraylist, watermark, coordinates, FPS counter, target HUD, and more - all fully themeable.

  • Drag-and-drop positioning
  • 10+ built-in themes
  • Custom fonts & colors
  • Animated transitions
🎨

Plugin API

Extend Y0 with your own modules. The plugin API supports Java and Kotlin with full access to the module system, event bus, and rendering engine.

public class MyModule extends Module {
  @Override
  public void onEnable() {
    chat("Hello from Y0!");
  }
}
